# Responsive-Flexbox-Layout
A responsive layout created using CSS Flexbox.

## Features
- Built using modern CSS Flexbox
- Responsive behavior with flex-wrap
- Clean spacing using gap
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3 (Flexbox)

## What I Learned
- Flexbox container vs items
- flex-wrap and flex-shrink behavior
- Difference between margin and gap
- Building responsive layouts without floats
